# Relationship Assistant Vision

## Purpose

Define the strongest long-term product direction for Prosepal without changing
the current app's core promise.

## Core Idea

Prosepal should evolve from a one-off message generator into:

**An AI assistant for staying thoughtful with the people who matter.**

The current message-generation flow remains valuable, but the stronger product
position is not "AI writes card messages." The stronger position is helping a
user maintain meaningful personal communication over time.

## Product Promise

Prosepal helps users:
- remember important people and moments
- say the right thing with less stress
- sound thoughtful without sounding generic
- keep relationships warm through consistent, well-timed communication

## Why This Direction Is Stronger

This direction is more durable than generic text generation because it adds:
- repeated use instead of one-off novelty
- personal context instead of stateless prompts
- timing and memory instead of single-screen output
- a clearer emotional job-to-be-done

The value is not only "write this message." The value is:
- "help me show up well for the people I care about"

## Product Pillars

### 1. Thoughtful drafting

Help the user create a message from scratch when they need one quickly.

Examples:
- birthday
- anniversary
- thank you
- condolence
- apology
- check-in

### 2. Rewrite and improve

Help the user refine something they already started.

Examples:
- make this warmer
- shorten this
- sound less awkward
- make this feel more sincere
- make this sound more like me

### 3. Relationship memory

Store lightweight context that improves future suggestions.

Examples:
- names
- important dates
- tone preferences
- recurring events
- shared details the user wants reflected in future messages

### 4. Timely prompting

Help the user remember when to reach out.

Examples:
- upcoming birthdays
- anniversaries
- follow-up reminders
- "you have not checked in with this person for a while"

## What Prosepal Should Feel Like

Prosepal should feel:
- personal
- warm
- calm
- trustworthy
- practical

It should not feel:
- like a generic chatbot
- like a mass-content generator
- like a novelty toy
- like a productivity tool built for teams

## Boundaries

Prosepal should stay focused on personal communication.

Good fits:
- cards
- texts
- short notes
- meaningful personal messages
- emotionally sensitive communication

Poor fits:
- generic marketing copy
- business writing for teams
- broad "AI writer" positioning
- high-volume spammy generation

## Strategic Implication

Near-term product work should prefer features that increase:
- repeat usage
- personal relevance
- emotional clarity
- trust in the output

Features that only increase breadth without improving those qualities should be
treated as lower priority.

## Pass Criteria

This vision is being followed when new product decisions clearly strengthen at
least one of these:
- repeat personal use
- relationship context
- better phrasing under emotional pressure
- timely thoughtful communication

If a proposed feature makes Prosepal broader but less personal, it is probably
moving in the wrong direction.
