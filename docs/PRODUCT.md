# Product contract

ProsePal is a small, enjoyable iPhone app for helping someone write a thoughtful
personal message. Keep it straightforward, reliable, honest about privacy and
routing, and easy to maintain.

## Settled boundaries

- Core loop: person/relationship → moment → optional real detail/guidance →
  explicitly request writing → review/edit/adjust → copy, share or deliberately save.
- The writer controls the wording and the destination. Never automatically send.
- Never silently destroy recoverable writing or invent personal facts.
- Personalisation, relationship memory and saved history are deliberate.
  Guidance is skippable; do not build an intake/interview product.
- Prefer on-device everyday writing where available. Online processing requires
  truthful permission and provenance; do not promise privacy from a route label.
- Provider/model names are not product UI. Sensitive treatment is not a Premium gate.
- First use must not force an account or immediate paywall. Premium claims must
  match actual access/limits; never promise unlimited use from finite policy.
- Keep the core loop accessible. Prefer system controls and simple degraded states.
- Prefer removing optional machinery over adding infrastructure that the writing
  job does not need.

## Out of scope

Chatbot/document editing, counselling, crisis assessment/intervention, bespoke
moderation engines, relationship scoring/guilt systems, automatic sending,
Flutter recreation, Android work, and speculative provider/platform frameworks.
Sympathy, bereavement, grief and difficult emotional messages remain valid uses.
Optional system entry points ship only when qualified without weakening the core loop.

## Open decisions — do not infer settled scope
