# Historical Architecture

These files preserve architecture directions that shaped the native rewrite but
are no longer current implementation instructions.

- [AI Gateway Strategy 2026](./ai-gateway-strategy-2026.md) — the complete
  pre-implementation gateway decision framework, provider abstraction,
  evaluation, operations, and rollout reasoning.
- [Native 2026 Technical Direction](./native-2026-technical-direction.md) — the
  product and Apple-stack direction that started the native rebuild.

Use [Native architecture](../../engineering/architecture.md) and
[AI generation](../../engineering/ai-generation.md) for current behaviour. The
historical strategy files remain whole because section-level splitting would
lose their original decision sequence and make the snapshot harder to audit.
