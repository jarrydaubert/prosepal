# Historical Design Explorations

This folder contains non-current visual alternatives retained to explain past
layout decisions.

- [Settings layout explorations](./settings-layouts.html) compares the former
  baseline with grouped-card, compact-grid, segmented, and drawer approaches.

The HTML file is intentionally self-contained so it can be opened and compared
without a build step. Current UI behaviour lives in the SwiftUI source and the
[plain-English app guide](../../guide/app-guide.html).
