# ProsePal visual source

This bundle contains web-rendered visual assets, components and exploratory UI
kits. Preserve assets used by the design renderer; they are not implementation
or product truth. Inspect SwiftUI source and [PRODUCT](../docs/PRODUCT.md) before
using visual copy, route labels or controls as engineering requirements.

`styles.css` imports tokens and component styles. Components expose JSX, TypeScript
and prompt files; `ui_kits/prosepal/` contains the selected visual exploration.
Apple font/icon substitutes here are for web rendering. Current app styling is
owned by `prosepal-ios/Sources/ProsePalUI/`.
